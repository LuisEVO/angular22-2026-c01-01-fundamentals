# EventHub

Proyecto integrador del curso Angular 22 Fundamentos.

El repositorio evoluciona progresivamente durante las ocho sesiones del curso.
Los checkpoints disponibles se identifican mediante tags Git como
`f01-start`, `f01-solution`, `f02-start`, etc.

## Requisitos

- Node.js 24 (`>=24.15.0 <25`; versión certificada: `24.16.0`, ver `.nvmrc`)
- npm

## Instalación

```bash
npm ci
```

## Desarrollo

```bash
npm start
```

La aplicación queda disponible en `http://localhost:4200/`.

## Build

```bash
npm run build
```
