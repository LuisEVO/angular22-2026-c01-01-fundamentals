# Session Materials

Each session uses the same source structure:

```text
docs/sessions/<session>/
├── storyboard.md
├── lab-guide.md
├── instructor-guide.md
└── visual-assets.md
```

## Naming

- Fundamentals: `f01` ... `f08`
- Advanced: `a01` ... `a10`
- Microfrontends: `m01` ... `m06`

All repository, file, and folder names must be in English and use kebab-case unless an Angular convention requires otherwise.

## Source of truth

- GitHub: editable text sources, technical specs, code, manifests, and status.
- Google Drive: approved binary deliverables such as DOCX and PPTX.
- Chat attachments: drafts only until explicitly approved and promoted.

## Promotion rule

A material becomes official only after:

1. review;
2. explicit approval;
3. source update in GitHub;
4. binary upload/replacement in Drive when applicable;
5. status update in `docs/materials-index.md`.
