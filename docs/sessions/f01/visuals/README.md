# F01 Visual Asset Pack — Full

This package contains the full visual asset pack for **F01 — Introduction to Angular 22 and first components**.

## Workflow

- Diagram source is stored as `.d2` when the visual is conceptual or structural.
- Final delivery assets are `.svg`.
- Slide composition happens later inside the official PowerPoint template.
- Code blocks preserve **semantic indentation exactly**. In SVG this is implemented through per-line horizontal offsets instead of leading spaces.

## Folders

- `sources/` → versionable D2 sources
- `manifest.json` → structured inventory
- `render-d2.sh` → helper script to re-render D2 locally once the D2 CLI is installed
